にっぽん ちず たんけん（小学生向けの日本の地理アプリ）

このアプリについて

  • 47都道府県の名前と位置・形、県庁所在地、7地方区分ととなりの県、地形（山・川・平野・湖・半島・島）、名所・名物、日本のはしの島を、地図を見ながら練習できます。
  • 30日間 無料でためせます（0円・お試しが終わっても自動で課金されません）。そのあとも続けるときは、月額300円（税込）の登録で、すべての機能を使えます。
  • 広告なし。お子さまが使う画面には、外部へのリンクや購入の案内はありません。
  • 記録や名前は端末の中だけに保存し、外部に送りません（プライバシーポリシー）。
  • インターネットにつながっていなくても使えます。

料金・お試し・解約

料金はいくらですか？

はじめの30日間は無料でお試しできます（0円）。そのあとも続けて練習するときは、月額300円（税込）の自動更新サブスクリプションに登録してください。無料版・有料版の区別はなく、お試し中も登録中も、すべての機能を同じように使えます。年額のプランはありません。

お試しの前でも、アプリを入れてから最初の1回（10問）だけ、練習を体験できます。

30日間のお試しは、どうやって始めますか？
  1. 「おうちのかたへ」を開きます（保護者用の暗証番号で開きます）。
  2. 「ご利用のプラン」で「30日間 無料で ためす（0円）」を押します。
  3. Apple の購入の確認（0円）が出るので、確認します。

ボタンを押した日を1日目として、30日目まで使えます（例：12月1日に始めたら12月30日まで）。「ご利用のプラン」に「お試し中：あと○日（○月○日まで）」と出ます。

お試しは、はじめての方のみご利用いただけます。前に月額の登録をしたことがある Apple ID では、お試しのボタンは出ません（「ご利用のプラン」に「お試しは、はじめての方のみご利用いただけます」と出ます）。

お試しが終わったら、自動でお金がかかりますか？

かかりません。お試しは0円の購入で、終わっても自動で月額の登録には切り替わりません。終わる3日前から、「ご利用のプラン」にお知らせが出ます。「この30日間」のタブでは、お試しの間に解いた問題・おぼえた都道府県・正答率の伸びなどをふりかえれます。

お試しが終わったあとは、練習はできなくなりますが、記録（たびの ちず・キャラクター・バッジ・カレンダー・学習レポート）はなくならず、見ることとバックアップはこれからもできます。あとから登録すれば、続きから練習できます。

月額の登録のしかた

「おうちのかたへ」→「ご利用のプラン」の「月額300円（税込）で登録する」を押し、Apple の購入の確認で登録します。お試しを始める前でも、お試し中でも登録できます（登録すると、その日から月額が始まります。お試し中のときは、お試しの残りの日数はなくなります）。お試しを使わずに登録した場合、そのあと登録をやめても、お試しは使えません。お支払いは Apple ID で行われ、1か月ごとに自動で更新されます。更新日の24時間前までに解約しないと、次の月も更新されます。

解約のしかた

iPhone・iPad の「設定」→ 自分の名前 →「サブスクリプション」で、このアプリを選んで「サブスクリプションをキャンセルする」を押します。アプリの「おうちのかたへ」→「ご利用のプラン」の「登録の確認・解約」からも、同じ画面を開けます。

解約しても、その月の終わり（次の更新日の前）までは使えます。アプリを削除しても、サブスクリプションは解約されません。

料金・お支払い・解約・返金については、特定商取引法に基づく表記にもまとめています。

入れ直したら・機種を変えたら、お試しや登録はどうなりますか？

お試しと登録は Apple ID に記録されています。同じ Apple ID なら、入れ直したり新しい端末に入れたりしても、そのまま引き継がれます（お試しを最初からやり直すことはできません）。表示が戻らないときは、「ご利用のプラン」の「購入を復元」を押してください。

記録（名前・たびの ちず・キャラクター・カレンダー・学習レポートなど）は端末の中だけにあるので、アプリを削除すると消えます。前に「💾 きろくを ほぞん」で作ったファイルがあれば、入れ直したあとで「おうちのかたへ」→「記録と設定」→「📂 きろくを よみこむ」で読みこむと、続きから使えます。

家族の端末でも使えますか？（ファミリー共有）

ファミリー共有に対応しています。購入した人の家族グループの家族（きょうだいの端末や、保護者の端末など）も、追加の料金なしで使えます。家族の端末で使えないときは、その端末の「おうちのかたへ」→「ご利用のプラン」→「購入を復元」を押してください。

子どもが勝手に購入しませんか？

購入・登録のボタンは、保護者用の暗証番号で開く「おうちのかたへ」の中だけにあります。お子さまが使う画面には、購入の案内は出しません（練習できないときは「おうちのかたに きいてね」とだけ出ます）。

お子さま用の Apple ID で「承認と購入のリクエスト」をオンにしている場合は、保護者の方の承認を待つ状態になります。承認されると使えるようになります。

よくある質問

保護者向けの画面（おうちのかたへ）はどこですか？

はじめの画面の「おうちのかたへ」を押してください（iPad の横向きではカレンダーの下、iPhone ではいちばん下にあります）。ご利用のプラン、学習レポート、この30日間のふりかえり、記録のバックアップ、地図のデータの出典があります。名前の変更は「⚙️ せってい」から、保護者用の暗証番号で開きます。

はじめて開くときは、大人向けの確認問題に答えてから、保護者用の暗証番号（4けた）を決めます。確認問題は、表示された数字を指示どおりに並べ替えるなどして入力するものです。

暗証番号をわすれました
  1. 暗証番号の画面で「暗証番号をわすれた」を押します。
  2. 大人向けの確認問題に答えます。
  3. 新しい暗証番号を決めます。お子さまの記録はそのまま残ります。
機種変更のときに記録を引き継げますか？
  1. 今の端末で「おうちのかたへ」→「記録と設定」→「💾 きろくを ほぞん」を押し、「"ファイル"に保存」から iCloud Drive などに保存します。
  2. 新しい端末にアプリを入れ、「おうちのかたへ」→「記録と設定」→「📂 きろくを よみこむ」で、そのファイルを選びます。

暗証番号は端末ごとの設定なので、引き継がれません。新しい端末で決め直してください。

ウェブ版「にっぽん ちり クイズ」の記録を引き継げますか？
  1. ウェブ版の「おうちのかたへ」で「💾 きろくを ほぞん」を押し、ファイルを保存します。
  2. アプリの「おうちのかたへ」→「記録と設定」→「📂 きろくを よみこむ」で、そのファイルを選びます。

カレンダー・おぼえた都道府県・まちがえた問題を引き継ぎます。おぼえた都道府県に合わせて、地方スタンプなども受け取れます。お試しは新しく始まります。

「おぼえた！」になるのは、どんなときですか？

同じ都道府県の問題に3回続けて正解すると「おぼえた！」になり、「たびの ちず」でその都道府県が地方の色でぬられます。地方の都道府県をぜんぶおぼえると、地方スタンプがもらえます。あとでまちがえても、たびの ちずの色は消えません（いまの覚えぐあいは「おぼえぐあい」で見られます）。

地図に小さな島がのっていません

見やすくするために、20km² より小さい島の多くは省いています。教科書や地図帳と同じように、竹島・尖閣諸島は印と名前で、沖縄県・奄美群島と小笠原諸島は枠の中に表示しています。日本の東西南北のはしの島（択捉島・南鳥島・沖ノ鳥島・与那国島）は「日本の はんい」で学べます。

記録を消したいときは？

アプリを端末から削除すると、記録・名前・設定はすべて消えます。バックアップのファイルを作っていた場合は、そのファイルも削除してください。

音が鳴りません

iPhone・iPad が消音モード（マナーモード）になっていると、効果音が聞こえないことがあります。消音を解除し、音量を上げてください。アプリの「⚙️ せってい」で「こうかおん」がオンになっているかも確かめてください。
